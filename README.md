# Oficina 3D

Galeria dos objetos 3D desmontáveis que o Adriano cria com o Claude. Cada ficha abre o objeto funcionando: dá para girar, cortar, isolar a peça que trabalha e ler os números reais.

- `index.html`: o painel da galeria
- `catalog.json`: o banco de dados (uma ficha por objeto, OF-001, OF-002…)
- `objetos/`: cada objeto é uma página HTML única, offline
- `thumbs/`: miniaturas
- `ferramentas/`: o empacotador, o capturador de telas e a skill `oficina-3d`

Os objetos são feitos com o motor [Teardown](https://github.com/elvarofficial/teardown) (MIT). Os três primeiros (V8, trem de pouso do Cessna 337 e Strandbeest) são os exemplos que vêm com ele.
